# Analisis Ventas - Biformato CR

Reporte de Sales Flash (Bodegas + Descuentos, Costa Rica) - comparativo Julio vs Agosto 2026.

## Contenido
- KPIs de Venta Julio/Agosto, Plan Total y % Logro
- Filtros: Periodo (por dia), Formato, Gerente Senior, Tienda, Cumple Plan Extendido
- Grafica de tendencia diaria (Julio, Agosto, Plan, y tiendas que ganan el Plan Extendido)
- Tabla de Cumplimiento por Gerente Senior
- Tabla de Cumplimiento por Tienda
- Tabla de Detalle diario (31 dias de Julio, Agosto hasta el dia de corte)

## Como actualizar
Este sitio se sirve directo desde `index.html` via GitHub Pages. Para actualizar:
1. Regenerar/editar `reportes/sales_flash_cr_diario_bodegas_descuentos.html` en el repo de trabajo local
2. Copiarlo a este repo como `index.html`
3. Commit + push a `main`

Generado con datos de Power BI - Sales Flash Report Operaciones (PBI_D&A: Finance Product).
